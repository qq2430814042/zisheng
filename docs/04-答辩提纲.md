# 《字·生》答辩提纲与问答准备

## 一、30 秒电梯陈述

《字·生》是一件让汉字"活起来"的交互式网页作品。我们用约两万枚实时粒子作为数字笔墨，让"日、月、山、水、人"五个基础象形字在滚动中从甲骨文一路"生长"到楷书；观众还能亲手把"日"和"月"合成为"明"，体验会意造字的智慧。作品全部画面与音效由程序实时生成，浏览器打开即用，希望让古文字从静态展陈变成可看、可玩的数字体验。

## 二、三分钟结构化讲解

1. **为什么做**（30 秒）：古文字离年轻人越来越远；静态展陈传达不了"字的生长"。
2. **做了什么**（60 秒）：五幕演变 + 一字千年时间轴（全量字库 14,873 字）+ 构字 + 写字（手写识别 + 名字星图海报）+ 三关认字 + 字量数据；现场演示一句：“滚动是时间，粒子是笔墨，互动是你亲手参与。”
3. **怎么做的**（60 秒）：字形栅格化→点云采样→粒子间建立对应关系→插值 morph；时间轴用双点云连续混合；手写用笔迹包围盒归一化+像素采样；自定义着色器；Web Audio 程序化音效；无任何外部素材。
4. **价值与展望**（30 秒）：语文教育、博物馆数字展陈、国际中文教育（面向留学生讲汉字故事）；下一步可扩展更多字、接入真实拓片数据、加入手写形体匹配。

## 三、高频问题与参考回答

**Q1：这和常见的"粒子文字"特效有什么区别？**
A：常见特效只是粒子拼成一个字；我们的核心是"演变叙事"——同一组粒子在五种字体形态间建立对应关系并流动重构，且有构字互动与完整章节结构，是作品而不是特效 Demo。

**Q2：字形准确吗？依据是什么？**
A：精选 30 字的古体笔画是参照甲骨学通行字形手绘的矢量数据；“一字千年”的全量字库（14,873 字）来自 MIT 许可的开源古文字字形数据集 character-evolution-dataset-1bit，经骨架化管线转为矢量笔画，并逐批抽样核对；解说文案按通行的文字学结论撰写，缺哪一阶段就诚实标注（如“甲骨文暂未见”）。

**Q3：团队分工？单人怎么完成这么多工作？**
A：我是单人参赛，负责创意、字形绘制、数值调参、测试与全部材料；开发过程中使用了 AI 编程助手辅助编写代码和整理文案，使用情况已按规定完整披露，AI 产出的每一行代码和文字都经过我逐项审查、运行验证与修改。

**Q4：AI 用在了哪些地方？如何证明你的实质性贡献？**
A：AI 用于代码草稿与文案润色，不生成任何美术素材。作品的选题、结构、视觉风格、交互设计、字形数据、调参与测试全部由我完成；我们保留了全过程记录与版本历史，可以展示。

**Q5：技术上最难的点是什么？**
A：①字形到点云的采样与去重；②两帧点云之间的粒子对应关系——我们按"分簇—角度—半径"排序，让每个字在自己的位置上演化，避免粒子乱飞；③在没有构建工具、没有外部素材的前提下保持约两万粒子 60fps 流畅渲染。

**Q6：为什么不用 Unity / UE？**
A：作品的目标是"任何人点开链接就能体验"。Web 端零安装、传播成本低，符合文化传播场景；WebGL 的实时粒子完全能满足表现需求。

**Q7：数据从哪里来？**
A：《说文解字》9,353 字、《康熙字典》47,035 字、《通用规范汉字表》8,105 字为文献通行数字；甲骨文约 4,500 单字（已释读约 1,500）、金文约 3,700 字为甲骨学公开统计口径，页面与文档均注明来源。

**Q8：作品的创新点用一句话概括？**
A：把"汉字演变"从静态知识变成一个可参与的系统：时间由观众掌控（滚动与时间轴），造字由观众亲手完成（构字），字迹由观众自己书写（写字），学习由竞猜检验（认字）——全流程参与式的汉字文化体验。

**Q9："一字千年"的连续演化是怎么实现的？**
A：每个字有五个点云（甲骨/金文/小篆/隶书/楷书）。时间轴拖动时，程序对相邻两个点云按滑块比例做逐点线性插值（对应关系按"分簇—角度—半径"预排序），所以是实时连续的计算，不是预设动画。

**Q10：手写功能用了识别算法吗？**
A：用了。我们集成了开源手写识别引擎 HanScribe（MIT，WASM + 12,361 字词表，模型本地/内嵌、离线可用）：笔迹预处理后由 BiLSTM 输出 Top-5 候选，高置信直接确认、否则 Top-3 点选；用笔顺中轴数据做客观评测，Top-1 达 97%、Top-3 达 100%。另有自研像素特征引擎兜底（196 常用字），引擎未就绪时仍有反馈；识别结果可直接联动“看它三千年”。

**Q11：如果让你继续完善，下一步做什么？**
A：①继续扩充罕见字的字形源，并把“简帛”等阶段延伸为独立章节（全量字库 14,873 字已上线）；②接入真实拓片与字书数据，做学术级的“字形时间轴”；③手写识别的读音与笔顺反馈，扩展为国际中文教育工具。

**Q12：作品的传播场景？**
A：语文课堂（汉字起源单元）、博物馆数字展项、国际中文教育（用视觉化解构象形字）、社交平台传播（短提取版）。

## 四、现场演示注意事项

1. 提前打开作品并预热（滚一遍全部章节），确保网络/本机顺畅；
2. 演示动线：开篇 → 甲骨文 → 快速滚到楷书 → 构字（日月→明）→ 字量 → 结束，全程约 50 秒；
3. 声音默认关闭，如现场环境允许可开启；
4. 准备离线备份：本地服务器 + 视频文件，防止网络故障。
