## 二、全局交互

- **章节切换**：滚轮 / ←→ 方向键 / 触摸横滑 / 翻页按钮 / 目录直达 / URL 深链接（#hash 可分享某章）
- **智能滚动**：浮层、目录、字库网格、面板内部滚动优先——滚到底才切章；合成/识别结果自动滚入视野
- **目录**：分组手风琴（点大标题直达组内首项）；位置刻度指示；当前项高亮；移动端抽屉；构字项「特色」徽章
- **HUD**：章节名、翻页按钮、目录、**存图**（任意画面导出 1920×1080 PNG）、**声音开关**、**音色选择**
- **移动端适配**：竖屏 / 矮屏安全区；面板内部滚动；320px 宽度起可用

## 三、音效系统（全部程序实时合成，零音频素材）

- 五声音阶（宫商角徵羽），**音高按笔画数分配**（2 画最低、7 画以上最高）
- **四种可选音色**：古琴（拨弦 + 低八度共鸣）/ 编钟（非谐 FM 金属声 + 泛音）/ 洞箫（双管微失谐 + 颤音）/ 水滴（下滑音 + 泛音）
- 切换即试听；偏好自动记忆（localStorage）
- **待机完全静音**，只在交互时发声；每次发声带轻微随机失谐，避免电味

## 四、数据与内容

- **演变字库**：14,873 字 × 5 阶段（甲骨 / 金文 / 简帛 / 小篆 / 隶书），共 28,776 个历史字形（开源数据集骨架化为矢量笔画，逐字标注可用阶段）
- **精选 30 字**：手绘矢量笔画 + 释读考据（点字看结构、本义）
- **构字组合**：8,600 组（精编 351：会意 54 / 形声 297，附自写解读；拆解 8,249：CCD 汉字拆解表，署名来源）
- **手写识别字典**：HanScribe 12,361 字离线模型
- 全部内容双语（中文为主、英文摘要与副题）

## 五、技术特性

- **纯前端、零外部请求**：单文件版 47.34MB（字体 + 模型 + 数据全内嵌），双击即用、断网可用
- **实时粒子渲染**：Three.js + 自定义着色器；数万粒子流畅演变；点云 LRU 内存管理（时间轴 / 认字 / 构字各自限容）
- **字体方案**：内嵌 LXGW WenKai 楷体——基础档 base64 + 5 个分块按 unicode-range 按需加载；`font-display: swap`
- **懒加载**：字库 59 分片按需拉取，首屏不等待
- **无障碍**：aria 标签、键盘可操作、focus-visible 高亮、`prefers-reduced-motion` 降级
- **零第三方图片 / 音频素材**：全部画面与声音由代码生成

## 六、工程与质量保障（开发侧）

- **构建工具链** `tools/`：`build_font.py`（字体分块）→ `build_evo.py`（字库骨架化管线）→ `build_unihan.py`（部首/笔画）→ `build_combo.py`（组合库生成）→ `build_single.py`（单文件打包 + 产物断言，防回退）→ `md_to_docx.py`、`ced_reader.py`
- **自动化探针** `assets/dev/`：交互截图 / 构字（7 用例：会意、部首归一、晚出字、未相遇、木+风=枫、囗+玉=国、滚动不翻页）/ UI（4 用例：入口跳转、音色记忆、按钮配色、四音色触发）/ 目录 / 筛选 / 手机端
- **许可合规**：CCD 数据附来源说明（tools/data/NOTICE-CCD.md）并在界面署名；OFL / MIT 许可随附
