# 《字·生》作品说明文档

## 一、基本信息

- 作品名称：《字·生》——汉字五体演变的粒子交互体验
- 参赛类别：指定命题（"科技+创意，讲好中国故事"）／自主命题（数字艺术与可视化设计）※以报名系统所选为准
- 作品形式：交互式网页作品（WebGL 实时渲染，浏览器直接运行）
- 作者：牛景飞（北京语言大学）
- 完成时间：2026 年 10 月

## 二、作品简介

《字·生》是一件以汉字五体演变为主题的沉浸式交互网页作品。作品以数万枚实时粒子为数字笔墨：观众横向切换章节，"日、月、山、水、人"五个基础象形字在甲骨文、金文、小篆、隶书、楷书五种形态之间流动重构，从远古刻痕一步步"长"成今天的模样；在"一字千年"章节，可任选 12 个基础象形字并拖动时间轴，亲手推动字形演化；在"构字"与"写字"章节，观众可以把"日"与"月"合成为"明"，也可以手写任意内容让粒子实时"接住"笔迹；"认字"章节则以甲骨文竞猜的形式检验所学。作品不同于静态展陈，让沉默的字符在粒子系统中重新"活"起来，兼具文化传播价值与科普教育意义。

## 三、创意来源与设计理念

**创意来源**：汉字是中华文明的基因，但在数字化时代，甲骨文、金文、小篆对许多年轻人而言日渐陌生；博物馆中的古文字展陈多为静态，难以让人直观感受"一个字如何一步步走到今天"。我们希望用粒子这一数字媒介，把汉字演变的千年历程压缩为一场可看、可玩的粒子剧场——让沉默的字符重新"活"起来。创作依据《说文解字》"象形者，画成其物，随体诘诎"的造字智慧，以及甲骨学中"日、月、山、水、人"等基础象形字的典型演变序列。作品取名《字·生》，既寓意汉字生生不息，也隐喻每一个字被观看时的一次"重生"。

**设计理念**：

1. **以粒子为笔墨**：粒子的聚散天然契合"笔画"与"生长"的意象；字的每一次演变，都是一次粒子重构。
2. **以时间为卷轴**：切换即时间流动，五幕对应五个时代，观众亲手推动历史。
3. **以色彩定气质**：甲骨文（骨白）、金文（铜金）、小篆（青玉）、隶书（素墨）、楷书（月白），每幕粒子颜色与背景光随时代流转。
4. **以互动通古今**：构字章节将"会意"造字法设计为可操作的互动，让观众从"看"变为"造"。

## 五、技术实现

- **架构**：原生 HTML / CSS / JavaScript（ES Modules），无构建工具、无后端；Three.js r160 本地部署。
- **粒子系统**：将字形栅格化后逐像素采样，得到约 20,000 个粒子的点云（移动端自适应约 9,000）；自定义 GLSL 着色器渲染（加性混合、柔和光点、时间微动）。
- **形态过渡**：点云按"分簇—角度—半径"排序建立粒子间对应关系；切换时逐点插值并施加缓动，实现字形之间"流动重构"的 morph 动画。
- **章节叙事**：横向章节切换驱动点云目标、粒子颜色与背景色的时序切换，颜色采用指数插值获得水墨晕染般的过渡；章节轨道、分级目录（刻度轴 + 当前位置 06/12）、翻页按钮与移动端目录抽屉均由程序生成，支持深链接（#act-seal）直达章节与刷新恢复。
- **程序化音效**：Web Audio API 实时合成——环境铺底（三振荡器 + 低通滤波 + 慢速 LFO）与五声音阶拨弦（每幕切换触发），无任何音频素材文件。
- **字形数据**：共 12 个基础象形字（日月山水人木火雨目口田大）；甲骨文、金文、小篆、隶书为手绘矢量笔画（Path2D 数据）；楷书与合体字采用系统楷体字形采样。
- **连续演化**："一字千年"章节采用双点云连续混合算法，时间轴拖动时按比例实时插值字形，实现"手推演化"的连续过渡。
- **手写采样**："写字"章节对手写笔迹进行包围盒归一化后像素采样，数千个笔迹点实时生成粒子云，实现"粒子接住你写的字"。
- **答对演变动画**："认字"章节答对后，甲骨文字形粒子平滑演变为楷书字形并显示释义。
- **适配与性能**：横屏五字一行、竖屏两列三行；设备像素比自适应；无网络请求依赖，离线可运行。

## 六、交互说明

1. **章节切换**：滚轮 / 方向键 / 左右滑动 / 界面箭头切换章节，右侧目录可直接跳转。
2. **一字千年**：点击任一字，拖动时间轴推动字形从甲骨文演化到楷书。
3. **构字**：在"构字"章节点击选择两个部件（如"日""月"），点击"合成"，粒子汇聚为新字并显示释义。
4. **写字**：在书写框中用鼠标或手指写字，点击"粒子化"，让粒子接住你的笔迹；"融入星河"让笔迹散入星云。
5. **认字**：读甲骨文字形，在四个选项中选出对应的现代字，答对后观看字形演变。
6. **章节导航**：右侧圆点可直达任意章节。
7. **声音开关**：左下角按钮开启/关闭程序化音景（默认关闭，尊重用户选择）。

## 七、原创性与素材说明

1. 全部画面由代码实时生成，**未使用任何第三方图片、模型、贴图或音频素材**。
2. 甲骨文、金文、小篆、隶书字形为参照甲骨学通行字形绘制的手绘矢量笔画，用于教学演示性质的文化表达。
3. 字体：楷体为操作系统内置字体（方正楷体），不随作品分发文件；如需在其他设备完整显示，建议在 Windows/macOS 环境浏览。
4. 字量数据为通行统计口径，来源：《说文解字》（东汉·许慎，收字 9,353）、《康熙字典》（清，收字 47,035）、《通用规范汉字表》（现代规范收字 8,105）及甲骨学公开统计（甲骨文已发现单字约 4,500、金文约 3,700）。
5. 依赖库：Three.js（MIT License），已在源码中保留其版权声明。
6. 作品为学生团队原创成果，未抄袭、未使用往届参赛作品，未发生多头申报。
