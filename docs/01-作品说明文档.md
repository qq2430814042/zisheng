# 《字·生》作品说明文档

## 一、基本信息

- 作品名称：《字·生》——汉字五体演变的粒子交互体验
- 参赛类别：指定命题（"科技+创意，讲好中国故事"）／自主命题（数字艺术与可视化设计）※以报名系统所选为准
- 作品形式：交互式网页作品（WebGL 实时渲染，浏览器直接运行）
- 作者：牛景飞（北京语言大学）
- 完成时间：2026 年 10 月

## 二、作品简介

《字·生》是一件以汉字五体演变为主题的沉浸式交互网页作品。作品以数万枚实时粒子为数字笔墨：观众横向切换章节，"日、月、山、水、人"五个基础象形字在甲骨文、金文、小篆、隶书、楷书五种形态之间流动重构，从远古刻痕一步步"长"成今天的模样；在"一字千年"章节，字库从 30 个精选基础象形字扩展到 1.4 万余个汉字（含《说文》小篆字头与甲骨、金文、简帛所见字）——任选一字拖动时间轴，即可亲手推动它从甲骨文（或它出现的最早年代）一路演化到楷书；在"构字"与"写字"章节，观众可以把"日"与"月"合成为"明"，也可以手写任意内容让粒子实时"接住"笔迹；"认字"章节则以甲骨文竞猜的形式检验所学。作品不同于静态展陈，让沉默的字符在粒子系统中重新"活"起来，兼具文化传播价值与科普教育意义。

## 三、创意来源与设计理念

**创意来源**：汉字是中华文明的基因，但在数字化时代，甲骨文、金文、小篆对许多年轻人而言日渐陌生；博物馆中的古文字展陈多为静态，难以让人直观感受"一个字如何一步步走到今天"。我们希望用粒子这一数字媒介，把汉字演变的千年历程压缩为一场可看、可玩的粒子剧场——让沉默的字符重新"活"起来。创作依据《说文解字》"象形者，画成其物，随体诘诎"的造字智慧，以及甲骨学中"日、月、山、水、人"等基础象形字的典型演变序列。作品取名《字·生》，既寓意汉字生生不息，也隐喻每一个字被观看时的一次"重生"。

**设计理念**：

1. **以粒子为笔墨**：粒子的聚散天然契合"笔画"与"生长"的意象；字的每一次演变，都是一次粒子重构。
2. **以时间为卷轴**：切换即时间流动，五幕对应五个时代，观众亲手推动历史。
3. **以色彩定气质**：甲骨文（骨白）、金文（铜金）、小篆（青玉）、隶书（素墨）、楷书（月白），每幕粒子颜色与背景光随时代流转。
4. **以互动通古今**：构字章节将"会意"造字法设计为可操作的互动，让观众从"看"变为"造"。

## 五、技术实现

- **架构**：原生 HTML / CSS / JavaScript（ES Modules），无构建工具、无后端；Three.js r160 本地部署。
- **粒子系统**：将字形栅格化后逐像素采样，得到约 20,000 个粒子的点云（移动端自适应约 9,000）；自定义 GLSL 着色器渲染（加性混合、柔和光点、时间微动）。
- **形态过渡**：点云按"分簇—角度—半径"排序建立粒子间对应关系；切换时逐点插值并施加缓动，实现字形之间"流动重构"的 morph 动画。
- **章节叙事**：横向章节切换驱动点云目标、粒子颜色与背景色的时序切换，颜色采用指数插值获得水墨晕染般的过渡；章节轨道、分级目录（刻度轴 + 当前位置 06/12）、翻页按钮与移动端目录抽屉均由程序生成，支持深链接（#act-seal）直达章节与刷新恢复。
- **程序化音效**：Web Audio API 实时合成——五声音阶拨弦（切幕 / 选字 / 作答时触发），每次拨弦带一层柔和低八度共鸣；**待机时完全静音**（不设常驻环境音，避免长时间电音干扰），无任何音频素材文件。
- **字形数据**：精选 30 个基础象形字（日月山水人木火雨目口田大牛羊女子刀弓门舟云天心手耳鸟土石竹犬）的甲骨、金文、小篆、隶书为手绘矢量笔画（Path2D 数据），并撰写释读考据；扩展字库 14,873 字取自开源古文字字形数据集 character-evolution-dataset-1bit（MIT License，约 26 万张历代字形图），经二值化、Zhang-Suen 骨架化、分叉合并与方向数字编码，压缩为约 31MB 的 59 个数据分片，按需加载、就地解码（含甲骨 1,779 / 金文 4,750 / 简帛 5,314 / 小篆 14,045 / 隶书 2,888 个字形）；每字按其真实收录阶段动态生成时间轴，仅见单一形态的字会如实说明。楷书与合体字采用内嵌楷体字形采样（基础字库 194KB 内嵌，扩展字按需下载 3.0MB 字体子集）。
- **连续演化**："一字千年"章节采用双点云连续混合算法，时间轴拖动时按比例实时插值字形，实现"手推演化"的连续过渡；阶段数随字而变（3—6 个阶段），点云采用 LRU 回收控制内存。
- **手写采样**："写字"章节对手写笔迹进行包围盒归一化后像素采样，数千个笔迹点实时生成粒子云，实现"粒子接住你写的字"；笔迹按书写速度控制笔画粗细并自动收尖（笔锋），支持撤销/重做。
- **手写识别（增强引擎）**：集成 HanScribe（MIT License）WASM 引擎与 12,361 字词表模型（约 7.5MB，本地/内嵌部署、离线可用）；笔迹经预处理后由 BiLSTM 推理输出 Top-5 候选概率，高置信直接确认、否则 Top-3 点选；自研"覆盖网格 + 笔画方向直方图 + 笔画数门控"像素特征作为引擎未就绪时的兜底。一次性书写多个字会提示"一次写一个字"；"跟着写"模式提供田字格描红底、笔画数对照与相似度评分（不校验笔顺），保证永远给出有效反馈。
- **名字图导出**：输入姓名生成粒子星图，可导出 1920×1080 海报（渲染缓冲导出 + 标题/日期合成）。
- **音效设计**：五声音阶拨弦（宫商角徵羽），音高按汉字笔画数分配（2 画最低、7 画以上最高）；只在交互发生时发声，静置无声。
- **字体内嵌**：LXGW WenKai（SIL OFL 1.1）子集化内嵌，跨平台显示一致。
- **考据联动**：识别或评分后，一键跳转"一字千年"并自动推演该字从甲骨到楷书的演变，同时弹出考据卡（造字法、本义、字形要点）。
- **答对演变动画**："认字"章节答对后，甲骨文字形粒子平滑演变为楷书字形并显示释义；知义关答对弹出考据卡。
- **辨识出题**：认形关从 30 字库随机出题，干扰项按字形模板相似度自动选取形近字；辨体关将同一字的两个历史阶段并排呈现。
- **适配与性能**：横屏五字一行、竖屏两列三行；设备像素比自适应；无网络请求依赖，离线可运行。

## 六、交互说明

1. **章节切换**：滚轮 / 方向键 / 左右滑动 / 界面箭头切换章节，左侧两级目录（开篇/演变/书写/辨字/数据/收束）可直接跳转；选字后可点"看它三千年的全过程"自动推演。
2. **一字千年**：点击任一字，拖动时间轴推动字形从甲骨文演化到楷书。
3. **构字**：在"构字"章节点击选择两个部件（如"日""月"），点击"合成"，粒子汇聚为新字并显示释义。
4. **写字**：自由书写 / 跟着写 / 名字图三种模式；一次性书写多个字会有提示；识别或评分后可一键查看该字的三千年演变与考据卡。
5. **认字**：三关制——认形（看甲骨选今字）、知义（选出本义，答对弹出考据卡）、辨体（判断两个字形的先后早晚）。
6. **章节导航**：左侧两级目录（大类分组 + 当前组自动展开，含位置指示）可直达任意章节，支持链接直达与刷新恢复。
7. **声音开关**：左下角按钮开启/关闭程序化音景（默认关闭，尊重用户选择）。

## 七、原创性与素材说明

1. 除下文明确标注的开源字体、开源手写识别模型与开源古文字字形数据集外，全部画面与音效由代码实时生成，**未使用其他第三方图片、贴图或音频素材**。
2. 精选 30 字的甲骨文、金文、小篆、隶书字形为参照甲骨学通行字形绘制的手绘矢量笔画，用于教学演示性质的文化表达；扩展 14,873 字的历代字形来自开源数据集 character-evolution-dataset-1bit（MIT License）的骨架化再加工，全部在"关于"页与文档中标注来源。
3. 字体：内嵌开源楷体 LXGW WenKai 子集（SIL OFL 1.1，约 165KB，覆盖作品全部用字），Windows / macOS / Android / iOS 显示一致，单文件版完全离线自洽；随包附 OFL 许可文本。
4. 字量数据为通行统计口径，来源：《说文解字》（东汉·许慎，收字 9,353）、《康熙字典》（清，收字 47,035）、《通用规范汉字表》（现代规范收字 8,105）及甲骨学公开统计（甲骨文已发现单字约 4,500、金文约 3,700）。
5. 手写识别使用开源项目 HanScribe（MIT License，含其 WASM 推理引擎与模型）；笔画数数据来自 hanzi-writer-data（提取自 Make Me a Hanzi，依 Arphic Public License），相关许可文本随作品打包。
6. 扩展演变字库的历代字形数据来自开源数据集 character-evolution-dataset-1bit（MIT License，© Leon Si），作品仅将其字形图像离线加工为矢量笔画点云用于粒子渲染；相关来源与许可在"关于"页、开发文档与提交材料中均已标注。
7. 依赖库：Three.js（MIT License），已在源码中保留其版权声明。
7. 作品为学生团队原创成果，未抄袭、未使用往届参赛作品，未发生多头申报。

## 九、运行环境

- 浏览器：Chrome / Edge 90+、Safari 15+、Firefox 90+（需支持 WebGL，建议 WebGL 2.0）
- 操作系统：Windows / macOS / iOS / Android
- 硬件：支持硬件加速的显卡，内存建议 4GB 及以上
- 运行方式：访问作品部署网址即可在线运行；亦可通过本地静态服务器打开项目文件夹运行，无需安装任何插件

## 十、附：本地运行方式

在项目根目录执行 `python -m http.server 8017`，浏览器访问 `http://127.0.0.1:8017`。
