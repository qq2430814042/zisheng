# 《字·生》演示视频脚本与录制说明

> 目标时长：约 3 分钟（以《作品材料提交规范》要求的时长与格式为准，下载后请核对并调整）

## 一、录制准备

1. 以本地或线上地址打开作品，按 **F11 全屏**，浏览器缩放 100%；
2. 关闭其他无关窗口与通知（微信、QQ 等），隐藏桌面图标（右键桌面 → 查看 → 取消"显示桌面图标"）；
3. 点击左下角"声音：开"开启程序化音景；
4. 使用录屏软件：Windows 自带 Xbox Game Bar（Win+G）或 OBS Studio，建议 **1080P / 60fps**；
5. 鼠标移动放慢、平滑，切换章节时停顿 0.5～1 秒再继续；
6. 录制完成后音轨若无声，可在剪映中补充背景音乐（推荐使用剪映自带无版权音乐）。

## 三、旁白完整文案（可直接配音）

> 汉字，是中华文明的基因。三千年来，它从刻痕长成笔墨。
> 甲骨文，刀锋刻入龟甲，先民把看到的日月山川，直接画成了字。金文，字走上青铜，笔画圆浑庄重。小篆，书同文，汉字第一次拥有统一的秩序。隶变，汉字从"画"变成了"写"。楷书，三千年的生长在此定格。
> 不止于观看——在这里，你可以亲手推着一个字走过三千年；可以写下一个“牛”字，让粒子认出它，再亲眼看着它从甲骨文长成今天的模样；可以把自己的名字化作一张粒子星图带走；可以把“日”与“月”合成“明”；还可以用甲骨文猜字，检验你读懂了多少汉字的童年。
> 从甲骨文四千余字，到《康熙字典》四万七千余字——汉字体系在时间里不断生长。
> 《字·生》——看一个字，从远古走到今天。

（配音可用剪映"文本朗读"生成，或本人录制，后者在答辩时更有说服力）

## 四、视频检查清单

- [ ] 全片无卡顿、无掉帧、无水印、无敏感信息（桌面文件、聊天窗口）
- [ ] 五个互动完整展示：时间轴拖动、构字合成、手写识别、名字图海报、认字答题
- [ ] 字幕与画面同步，字号足够大（评委多为远距离观看）
- [ ] 视频首尾各留 1 秒黑场/静帧，便于剪辑
- [ ] 导出 H.264 MP4，文件名按提交规范命名（如：作品编号-字生-演示视频.mp4）
