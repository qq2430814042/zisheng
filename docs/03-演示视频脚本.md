# 《字·生》演示视频脚本与录制说明

> 目标时长：约 4 分钟（官方要求 5 分钟以内；成片请以《作品材料提交规范》为准）

## 一、录制准备

1. 以本地或线上地址打开作品，按 **F11 全屏**，浏览器缩放 100%；
2. 关闭其他无关窗口与通知（微信、QQ 等），隐藏桌面图标；
3. 点击左下角 **"声音：关"** 按钮开启音效（点击后按钮变为"声音：开"；作品待机静音，只在交互时发声），上方可在四种音色（古琴 / 编钟 / 洞箫 / 水滴）间切换；
4. 使用录屏软件：Xbox Game Bar（Win+G）或 OBS Studio，建议 **1080P / 60fps**；
5. 鼠标移动放慢、平滑，切换章节时停顿 0.5～1 秒再继续；
6. 录制完成后音轨若无声，可在剪映中补充无版权背景音乐。

## 三、旁白完整文案（可直接配音）

> 汉字，是中华文明的基因。三千年来，它从刻痕长成笔墨。
> 甲骨文，刀锋刻入龟甲与兽骨；先民把看到的日月山川，直接画成了字——这是汉字的童年。金文，字走上青铜，笔画圆浑庄重。简帛，墨迹里藏着篆隶之间的过渡。小篆，书同文，汉字第一次拥有统一的秩序。隶变，汉字从“画”变成了“写”，笔锋从此有了速度。楷书，三千年的生长，在此定格。
> 不止于观看——字库从 30 个精选字扩展到 14873 个汉字；每个字都按它真实的生命阶段生长。有的字出生得晚，我们就诚实地说：它那时还没有出生。
> 汉字是积木。日与月相合，便有了"明"；你也可以亲手写下"水"和"可"——它们合成"河"。八千多组部件组合——会意的智慧，由你亲手拼出。
> 写下你的一笔一画，粒子会接住它。开源手写识别引擎一万两千多字的词表在本地推理，断网也能认——认出来之后点一下，就能看这个字三千年的样子。你也可以把名字写成一张星图，一键导出海报。认形、知义、辨体，三关过后，你会重新认识这些字。
> 从甲骨文四千余字，到《康熙字典》四万七千余字——汉字，一直在生长。
> 粒子如何生长？双点云连续混合，让相邻字形逐点插值；一万四千多字按需加载；自研与开源双识别引擎，让书写既准又稳。
> 三千年，字仍在生长。墙上的三十个字，只是序章。《字·生》——看一个字，从远古走到今天。

## 四、视频检查清单

- [ ] 全片无卡顿、无掉帧、无水印、无敏感信息（桌面文件、聊天窗口）
- [ ] 六幕画面 + 五个互动完整展示：简帛一幕、时间轴拖动、构字合成、手写识别、名字图海报、认字答题
- [ ] 字幕与画面同步，字号足够大（评委多为远距离观看）
- [ ] 视频首尾各留 1 秒黑场/静帧，便于剪辑
- [ ] 导出 H.264 MP4，≤1GB，文件名按提交规范命名（如：316056-字生-演示视频.mp4）
