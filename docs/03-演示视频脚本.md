# 演示视频录制清单（纯画面 · 无解说）

> 目标：3 分钟左右完整展示作品全部功能。只录屏幕操作，不需要旁白。
> 建议保留作品自身音效（左下角"声音"打开），画面与声音均来自作品本身。

## 一、录制设置

- 分辨率 1920×1080，帧率 30fps；输出 MP4（H.264）
- 浏览器全屏（F11），隐藏书签栏/扩展栏
- 打开方式：直接双击 `字生-单文件版.html`，或本地 http 服务下打开
- **匿名检查**：录屏画面里不要出现姓名、学校、微信、收藏夹等身份信息
- 名字图环节**不要输入真实姓名**，用示例字（如"字生"）
- 文件命名：`视频-字生-316056.mp4`（不带姓名）

## 二、操作分镜表（约 3 分钟）

| 时间 | 画面 / 操作 | 停留 |
|---|---|---|
| 0:00–0:06 | 开篇：粒子标题「字·生」静置 | 3s |
| 0:06–0:20 | 甲骨文：滚轮进入；点画面中的大字，弹出释读卡，关闭 | 卡停 2s |
| 0:20–0:34 | 金文 → 简帛：逐幕进入，每幕静置 | 各 4s |
| 0:34–0:48 | 小篆 → 隶书 → 楷书：逐幕进入 | 各 3–4s |
| 0:48–1:12 | 一字千年：点选「日」；拖动时间轴来回一遍（展示五体演变）；点「更多字 14,873」打开检索网格（部首选"水"、笔画选"8"），关闭；点「看它三千年的全过程」看 2s | 节奏放慢 |
| 1:12–1:42 | 构字：选「日」+「月」→ 合成「明」；展开解读；点「看它三千年」3s 后返回；切「手写」模式，写「水」+「可」→ 合成「河」；点「再来一组」 | 每步停 1–2s |
| 1:42–2:12 | 写字：自由书写写一个「字」→ 点「粒子化」；切「跟着写」点一次「评分」；切「名字图」输入"字生"→「生成」→ 点「保存图片」 | 各停 2s |
| 2:12–2:30 | 认字：切「困难」档；答一题（点正确选项，停留看释读反馈）；进入下一题 | 反馈停 2s |
| 2:30–2:38 | 字量：缓慢滚动，展示两组条形数据 | 4s |
| 2:38–2:46 | 尾声：点字墙上的任意一个字，看它的三千年 | 3s |
| 2:46–2:56 | 关于：停留展示开源致谢与素材版权 | 4s |
| 2:56–3:00 | 回到开篇，结束录制（可选：片尾加一张"作品编号 316056"静帧） | 3s |

## 三、可选加分项

- 每段开头加一行极简小字幕（如"构字·手写合成"），不用旁白也看得懂
- 剪辑时统一章节切换的节奏，去掉加载等待与误操作片段
